# FinBuddy repository scripts

| Script | Use |
| --- | --- |
| `check.sh` | Run the shared foundation, local link and contract checks |
| `check_foundation.py --ready` | Verify template structure, metadata and approved discovery decisions |
| `add_service_skill.py` | Register a real service and its continuation. Start with `--dry-run`. |
| `repository_ruleset.py` | Preview repository protection and apply an authorized settings change |
| `verify-hosting.mjs` | Verify a served FinBuddy revision and its Hosting assets |
| `version-bump.js` | Prepare an application version and changelog update |

Use the [test catalog](../docs/testing.md), [release plan](../docs/release-plan.md), and [service catalog](../skills/README.md) for scope and prerequisites.
